Project: Minesweeper Game.

Description: Code that will randomly generate a 5 by 5 array of mined and unmined locations.
From this, it will generate a second array where each location contains the number of mines
present in adjacent locations. It will present this second array to the player. The player
needs to identify the locations of the mines in the array. When the player has attempted the
puzzle, they can view the solution grid. The player can initially select the number of mines
they want in the grid (bewteen zero and 25).

Usage: Download and run the Python code.
